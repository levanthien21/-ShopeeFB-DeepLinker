Hướng Dẫn Lấy Page Access Token Meta (FB Developers)

Cách lấy Token Fanpage vĩnh viễn không bao giờ hết hạn chỉ với 4 bước đơn giản

Tại sao cần Page Access Token?

Meta (Facebook) yêu cầu Page Access Token để xác nhận bạn là Quản trị viên của Fanpage. Khi có Token, hệ thống máy chủ có thể đăng bài hoàn toàn tự động 24/7 mà bạn không cần phải mở tab trình duyệt hay ấn nút đăng thủ công.

1
Truy Cập Meta for Developers & Tạo App:

Vào developers.facebook.com -> Đăng nhập Facebook -> Chọn Ứng dụng của tôi (My Apps) -> Bấm Tạo ứng dụng (Loại: Khác / Doanh nghiệp).

2
Mở Graph API Explorer:

Vào mục Graph API Explorer -> Tại mục Meta App, chọn tên ứng dụng bạn vừa tạo.

3
Cấp Quyền Đăng Bài & Auto Reply Cho Fanpage:

Tại mục Permissions (Quyền), thêm đủ các quyền quan trọng sau:

pages_manage_engagement ⭐ (Trả lời cmt & Like) pages_messaging ⭐ (Inbox Messenger) pages_manage_posts (Đăng bài nuôi page) pages_read_user_content (Đọc cmt khách) pages_read_engagement pages_show_list

⚠️ LƯU Ý ĐẶC BIỆT CỦA META: Quyền pages_manage_engagement là BẮT BUỘC để bot có quyền đăng bình luận công khai trả lời khách dưới bài viết. Nếu thiếu quyền này, bot sẽ chỉ gửi được tin nhắn riêng Messenger!

4
Lấy Token & Dán Vào Công Cụ:

Tại ô User or Page (Góc phải Explorer), bấm chọn Tên Fanpage của bạn (nằm dưới mục Page Access Tokens) -> Bấm Generate Access Token.

✨ Công Nghệ Tự Động Hóa 2026: Nếu bạn lỡ tạo User Token, đừng lo! Chỉ cần dán vào ô Token rồi bấm nút "Quét Page", hệ thống sẽ tự động nhận diện tất cả Fanpage của bạn và lấy đúng Page Access Token để đăng bài trực tiếp!
