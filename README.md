# 🚀 ShopeeFB DeepLinker - Công Cụ Tạo Link Shopee Đăng Facebook Mở Trực Tiếp App

Công cụ giúp chuyển đổi link sản phẩm Shopee (hoặc link Shopee Affiliate) thành link bài viết trên Facebook với:
- **Thẻ xem trước (Open Graph) siêu đẹp**: Hiển thị ảnh bìa to, tiêu đề hấp dẫn, mô tả đầy đủ.
- **Deep Linking tự động**: Khách bấm vào trên điện thoại iOS/Android sẽ tự động mở thẳng vào App Shopee đã đăng nhập sẵn thay vì trình duyệt Facebook.
- **Đếm số lượt click**: Theo dõi hiệu quả của từng link.

---

## 1. Chạy thử trên máy tính (Local)

1. Mở Terminal / PowerShell tại thư mục này (`c:\Users\ASUS\Desktop\aff`).
2. Chạy lệnh:
   ```bash
   npm start
   ```
3. Mở trình duyệt truy cập: [http://localhost:3000](http://localhost:3000)

---

## 2. Đưa lên mạng miễn phí (Vercel) để có link thật đăng Facebook

Để có link online (dạng `https://ten-du-an.vercel.app` hoặc tên miền riêng của bạn):

### Cách nhanh nhất (qua GitHub & Vercel):
1. Đăng ký tài khoản miễn phí tại [Vercel](https://vercel.com) và [GitHub](https://github.com).
2. Đẩy thư mục này lên một GitHub repository cá nhân.
3. Vào Vercel, chọn **Add New Project** -> Chọn GitHub repo vừa tạo -> Bấm **Deploy**.
4. Vercel sẽ cấp cho bạn một đường link miễn phí (hoặc bạn có thể gán tên miền riêng vào mục Settings > Domains).

---

## 3. Cách sử dụng khi đăng bài lên Facebook
1. Dán link Shopee gốc hoặc link Shopee Affiliate vào công cụ.
2. Nhập tiêu đề và dán link ảnh sản phẩm.
3. Bấm **"Tạo Link Chuyển Hướng Facebook"**.
4. Sao chép link đã tạo và dán vào bài đăng hoặc bình luận trên Facebook.
